# Manufacturing_SPC — H-Acid Quality Engineering Project

## About This Project
This is a real-world quality engineering project focused on H-Acid
(1-amino-8-naphthol-3,6-disulfonic acid) batch chemical process monitoring
and improvement using Statistical Process Control (SPC), Design of Experiments (DOE),
and formal quality management tools.

> **Note:** The raw production dataset is proprietary and not included in this
> repository. Only the analysis outputs (control charts, capability reports, DOE plots)
> and quality deliverables are shared here for learning purposes.

## Folder Structure
- `minitab/charts/` — I-MR control charts (Purity, Iron, Moisture, pH, Ash)
- `minitab/Capability Analysis/` — Process capability reports (Cp, Cpk, Pp, Ppk)
- `minitab/DOE/` — Design of Experiments: main effects and Pareto charts
- `minitab/Defect_log/` — Pareto chart of defect types & Cause-and-Effect (Fishbone) diagram
- `docs/` — PFMEA, 8D Report, Corrective Action plan, Supplier Audit Scorecard, Final Report

## Tools Used
- **Minitab** — Control charts, capability analysis, DOE, Pareto, Fishbone
- **Excel** — PFMEA, supplier scorecard
- **Word / PDF** — Final report and quality deliverables

## Key Deliverables
- I-MR control charts for 5 critical quality parameters
- Process capability analysis (before-drift vs. full dataset)
- Full-factorial DOE to identify key process factors
- PFMEA with risk priority numbers (RPNs)
- 8D structured problem-solving report
- Corrective action and supplier audit documentation

## What You Can Learn From This Repo
- How to apply SPC to batch chemical manufacturing
- Reading and interpreting I-MR charts and capability indices
- Setting up and analyzing a DOE in Minitab
- Structuring quality deliverables: PFMEA, 8D, Corrective Actions
